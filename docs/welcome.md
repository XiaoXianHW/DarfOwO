# 欢迎来到我的博客

欢迎来到我的个人博客！这是一个使用 **React + Vite** 构建的现代化个人主页。

## 技术栈

这个博客使用了以下技术：

- **React 18** - 现代化的前端框架
- **Vite** - 快速的构建工具
- **Tailwind CSS** - 实用的CSS框架
- **Framer Motion** - 流畅的动画库
- **React Markdown** - Markdown渲染

## 功能特点

### 1. 响应式设计

完美适配各种设备，从手机到桌面端都有良好的体验。

### 2. 深色模式

支持明暗主题切换，保护你的眼睛。

### 3. Markdown支持

支持完整的Markdown语法，包括：

- 代码高亮
- 图片显示
- 表格
- 引用块
- 任务列表

## 代码示例

这是一个简单的React组件：

```jsx
import React from 'react'

const Welcome = ({ name }) => {
  return (
    <div className="container">
      <h1>Hello, {name}!</h1>
      <p>Welcome to my blog</p>
    </div>
  )
}

export default Welcome
```
